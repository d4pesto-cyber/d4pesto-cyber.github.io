Privacy policy – CranberryCrazyManagement

CranberryCrazyManagement is a personal tool used only by its owner to upload videos to the owner's own YouTube channel (CranberryCrazy) and Instagram account, and to read those accounts' statistics. It has no other users.

YouTube API Services

This tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service. See also the Google Privacy Policy.

What data is used

The tool accesses only the owner's own channel: it uploads videos, reads the channel's basic information, and reads its analytics (views, watch time). It collects no data from anyone else, uses no cookies, and shares nothing with third parties.

Storage

The access token and channel statistics are stored only on the owner's own computer. Statistics are kept to compare video performance and deleted when no longer needed.

Revoking access

Access can be revoked at any time at Google security settings.
